# VX-94 precision-bomb transformation

Three ten-exposure sequences preserve loaded, single-release and empty precision-bomb racks through the fighter-to-bomber wing transformation. Sixty independent EVAVO Art Studio-finished layers retain the 64x72 pivot, move with the bomber pylons, pass transparent-RGB inspection, and are selected from the live bomb count whenever external support stores do not occupy the pylons. Native Godot evidence loads every layer and renders all thirty gameplay combinations.
